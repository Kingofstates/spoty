# Spoty

Official Spoty Android music streaming and public download player.

### Features
- 🎵 Direct public downloads to `/storage/emulated/0/Download/Spoty/`
- 🏝️ Universal Dynamic Island and Origin Island media rhythm support
- 🪟 Blurry glass frosted navigation bar
- 🔄 Seamless in-app self-updater
